HOW IT WORKS
1
Train in Python. An IsolationForest learns the nominal envelope of 6 rover sensors (battery, motor current, chassis temp, pH, soil moisture, gas) from simulated testbed telemetry — 18 context features, not raw values.
2
Export every tree. All 64 trees — every split, threshold and leaf — are serialized to model.json. Deterministic guardrails (robust-z, stuck-value, transient, dropout) ship from the same training stats.
3
Run it in the browser. This page scores the live stream with the exact exported forest — verified bit-identical to scikit-learn (max diff 1.1e-16). No server, no API, no backend.
